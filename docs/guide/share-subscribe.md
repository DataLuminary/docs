# 分享与订阅

目标：把分析结果送到同事、大屏或业务系统，而不是只留在编辑器里。

## 常见方式

| 方式 | 适用 | 入口文档 |
|------|------|----------|
| 分享链接 | 登录用户按权限打开 | [分享总览](/share/) |
| 嵌入 | 业务系统 iframe / 第三方页 | [仪表盘嵌入](/share/embed) |
| 订阅推送 | 定时邮件 / 渠道投递渲染结果 | [订阅推送](/share/subscription) |

嵌入涉及令牌与域名白名单时，请研发同事对照 [第三方嵌入对接](/develop/embed-integration)。

下一步：[申请权限](./request-access.md)。
