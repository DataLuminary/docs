# 做一张仪表盘

目标：从数据集拖出图表，编排成可发布的一页。

## 步骤心智

1. 确认已有可用 [数据集](./connect-data.md)。  
2. 新建图表：选数据集、维度与指标、图表类型。  
3. 新建仪表盘：把图表放入网格或自由布局页。  
4. 需要页内分组时用布局插件（行 / 标签 / 轮播等），不要和整页坐标系混为一谈。  
5. 保存并按空间权限发布或分享。
