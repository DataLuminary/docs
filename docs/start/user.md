# 路径：普通用户

面向业务、运营、分析师与空间管理员——**按任务读，不必先啃架构。**

## 建议顺序

1. [产品概览](/product/) — 一分钟弄清 DataLuminary 是什么  
2. [指南首页](/guide/) — 任务清单总入口  
3. 按需点开下面任务
