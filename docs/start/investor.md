# 路径：投资者

一页纸叙事。细节链到白皮书与能力页，**不写融资条款与财务预测。**

## 问题

企业数据在增加，但「能看图」不等于「能决策」：缺口径治理、缺权限协作、缺可解释的 AI。传统 BI 与纯 ChatBI 往往各走一端——要么重报表轻洞察，要么模型答数不可审计。

## 方案

**DataLuminary = 全链路 BI + AI 数据洞察 + 插件化生态 + 私有化交付。**

拖拽、AI 分步打磨、一句话生成，共用同一套数据集、图表、仪表盘与权限；AI 产出的是平台配置与可编辑草案，数字来自平台查询。

## 差异化（相对常见竞品心智）

| 点 | 含义 |
|----|------|
| 数据集中枢 | 图表不直连库表乱写 SQL；口径进语义模型 |
| 微内核 + 插件 | 行业图、连接器、版式可扩展，不进内核 |
| 身份与生态 | 默认 LuminaryWorks 统一账号；私有化走企业 SSO |
| 私有化友好 | 面向隔离网络与企业差异交付，而非仅云 SaaS |

对照表见 [竞品对比](/migrate/compare)。

## 技术壁垒（一句话）

全栈 TypeScript 契约（DataView + DataTalk）+ 查询/权限/插件同一状态模型，使 AI 协作与二次开发落在同一套 Schema 上，而不是页面事件网。

展开：[架构概览](/develop/architecture) · [设计理念](/product/design-philosophy)。
