# 大屏导航菜单

大屏导航（`screen-nav-menu`）是 DataLuminary 的 **装饰 / 导航** 面板：横向菜单，不绑定数据集、不发起查询。菜单项点击只告诉仪表盘「选中了哪一项」，具体切页、跳转或高亮由仪表盘 **交互规则** 完成。

## 适用场景

- 指挥大屏顶栏：概览 / 运行 / 告警 等栏目
- 与标签页、轮播配合：点菜单切换当前页
- Demo / 行业模板里的装饰导航条

## 使用方式

1. 在仪表盘编辑器（通常是自由布局大屏）添加 **大屏导航**。
2. 在配置里填写：

| 配置项 | 作用 |
|--------|------|
| **标题** | 可选；有标题时菜单与标题左右分布 |
| **菜单项** | `key:label` 列表，逗号分隔，最多 16 项（如 `overview:总览, ops:运行`） |
| **当前项** | 默认选中的 `key` |
| **对齐** | 左 / 中 / 右 |
| **字号 / 强调色** | 视觉；强调色随用户大屏主题，不受产品品牌色板限制 |
| **可点提示** | 光晕 / 描边 / 无 |

3. 打开该面板的 **交互** Tab，为需要的 `key` 添加 `menuItem` 规则，效果可选：
   - **切页**（`activateSlot`）→ 指定标签页或轮播
   - **打开链接 / 仪表盘**
   - **强调** 其它面板

插件本身 **不会** 改浏览器地址、也不会自己切布局页。

## 不要和这些能力混淆

| 需求 | 正确做法 |
|------|----------|
| 筛选图表数据 | 用筛选控件或图表联动，不要用导航菜单冒充 Action |
| 本图下钻 | 在图表查询里开下钻 |
| 只换一组图 | 用布局 **标签页**，再用本组件的菜单去切那个容器 |
| 点四级告警计数 | 那是 [状态告警卡片](./status-alarm-card.md) 的卡内筛选，与本组件无关 |

## 工程说明

- 能力：`requiresQuery: false`，`emitsInteraction: ["click", "menuItem"]`
