# 状态告警卡片

状态告警是 DataLuminary 中面向 **监控 / 大屏** 的图表组件：按阈值把实体分成「告警 / 预警 / 提示 / 正常」，顶部显示四级计数，下方列出明细。点击某一级计数，会 **只切换本卡片下方的明细列表**，无需再配图表联动。

## 适用场景

- 站点、设备、通道等实体的状态一览
- 大屏右下角「告警摘要」：一眼看到各级数量，再点进某一级看名单
- Demo / 模板中的监测类面板（如「大屏可视化模板 · 监测」）

## 使用方式

1. 在仪表盘编辑器中添加图表类型 **状态告警**。
2. 与普通图表一样绑定数据集，并配置：
   - **1 个指标**：状态数值，或可识别的状态字符串（如 `warn` / `ok`）
   - **1 个维度**：实体名称（如站点名）
3. 在右侧配置面板设置分级与列表：

| 配置项 | 作用 |
|--------|------|
| **预警阈值 ≥** | 达到该值（且未达告警阈值）计为「预警」 |
| **告警阈值 ≥** | 达到该值计为「告警」 |
| **列表上限** | 明细最多显示多少条 |
| **等级样式（文案 / 颜色）** | 为告警 / 预警 / 提示 / 正常分别自定义显示文案与强调色（例如告警鲜红、预警黄色）。留空则使用界面默认文案与颜色 |
| **列文字颜色** | 按维度、指标分别设置文字颜色。名称留空跟随仪表盘文字色；数值留空仍按告警等级着色 |
| **数值格式** | 明细中数值的小数位 / 量级 / 单位（不改变分级） |

默认阈值：预警 ≥ 60、告警 ≥ 80。大屏模板常按业务改成更小的阈值（例如预警 ≥ 4、告警 ≥ 8）。

低于预警阈值的数值一般计为「提示」。仅当指标本身是命名状态（如 `ok` / `normal`）时，才会出现「正常」计数；纯数值默认规则下「正常」可能一直为 0，这是预期行为。

## 点击四级计数（状态摘要 Tab）

进入预览 / 分享页后：

| 操作 | 结果 |
|------|------|
| 未点击 | 下方显示全部明细 |
| 点击「告警」等某一级 | 下方只显示该级；底部条数同步变化 |
| 再点同一级 | 取消筛选，恢复全部 |
| 点击计数为 0 的级 | 下方显示「没有查询到数据」，条数为 0 |

深色大屏上等级标签为浅色 / 白字，数字与边框用各级强调色；选中态有半透明底，便于辨认。

## 不要和这些能力混淆

| 需求 | 正确做法 |
|------|----------|
| 只想切换本卡明细 | 直接点四级计数即可，**不用**配联动 |
| 要点击后换成完全不同的几张图 | 使用布局 **标签页（Tab）** 容器，每页各放一套图表 |
| 要点击后过滤画布上 **其它** 图表 | 使用 **图表联动**，且过滤字段必须是数据集里的真实维度（不是本卡算出来的等级） |

当前版本中，四级等级是在浏览器内按阈值算出来的，**不会**自动驱动旁边的「告警明细」滚动表或其它面板。若业务需要整屏联动，请先在数据侧提供真实的告警等级字段，再配置联动。
