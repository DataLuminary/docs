## 文档与交付暴露的需求

| 主题 | 为何提出 | 期望结果 |
|------|----------|----------|
| 公共 API 文档站 | 开发区仅有索引，无稳定 OpenAPI 镜像 | 标出稳定端点集或自动生成文档站 |
| 审计日志 / 审计中心 | 企业安全问卷高频 | 可查询的操作审计（谁、何时、对何资源） |
| 合规认证叙事 | 等保 / SOC2 / ISO 无现成证书页 | 按部署形态给出合规路径说明（非口头承诺） |
| 多租户隔离边界白皮 | 交付时常被追问 | 空间 / 组织 / 部署拓扑的明确边界表 |
| 场景 Demo 展厅产品化 | 已有说明页，展厅体验需持续对齐 | 可一键体验的场景包与文档同步 |
| 生态集成「已通 / 规划中」 | 六产品叙事需可核验 | 在生态页维护集成状态表 |

## 产品能力方向（摘要）

具体里程碑以 MetaRepo [`plan/`](https://github.com/DataLuminary/DataLuminary-Platform/tree/main/plan) 为准；本页只保留**用户可感知**的方向摘要，避免与工程排期双写冲突。

- 更完整的迁入工具链（Grafana / DataEase 等）  
- 嵌入与订阅的企业级运维面（监控、配额、审计）  
- AI 洞察在私有化模型与知识库场景的加深
